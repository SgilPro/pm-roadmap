Linkju MVP — Product Requirements Document

版本 1.0 · 2026 Q2 · 作者：jobshih（PM/Co-Founder）

一、產品概述

Linkju 是以社區管理者為核心的 SaaS 平台，定位為「管理者的 OS」（Manager's Operating System）。台灣約有 40,000 個住宅社區，其中 26,000 個尚未數位化。現有龍頭（智生活）以廣告模式運營，造成平台利益與社區利益長期衝突。

Linkju 以管理效率為第一差異化點，向委員會收取 SaaS 月費，居民免費且無廣告使用——透過商業模式根本性修正了智生活的結構缺陷。

目標用戶 A（主）

社區管理者
100–250 戶社區的專任或兼任管委、管理員；需要跨頻道集中處理包裹、公告、報修；平均非技術背景，習慣 LINE 群組。

目標用戶 B（次）

社區居民
同棟住戶；主要動機是即時接收包裹通知、查看公告；不願意安裝多一個 App，需要 LINE OA 作為低摩擦入口。

銷售決策者

物業管理公司 / 主委
銷售週期 8–12 週；決策考量：成本效益（vs 現有工具）、採用門檻（居民端）、合規性（個資）。

二、業務目標

3 個月 OKR

  • 完成 1 個試點社區上線（≥ 50 戶）
  • 居民週活躍率 ≥ 40%
  • 包裹通知開啟率 ≥ 70%
  • 工單平均回應時間 <24 小時
  • 管理者 NPS ≥ 7/10

商業模式驗證

  • SaaS 月費（per community）付費意願確認
  • 管理費代收功能需求調查（P2 規劃依據）
  • 廣告收入（永遠不做）
  • 管理費代收（MVP 外，P2 功能）
  • Marketplace（修繕媒合）

三、P0 功能需求（Launch Scope）

F-01 包裹到貨通知

類型使用者故事驗收條件優先級
管理者管理者掃描 / 手動登記包裹後，系統自動推播通知給對應居民通知到達時間 <60s；支援多件並行登記；居民可確認取件P0
居民居民收到通知後可查看包裹資訊（件數、到達時間）App 內可見詳情；無通知者可以 LINE OA 查詢P0
系統超過 48 小時未取件時，自動發二次提醒逾期提醒；可設定關閉；不重複推送P1

F-02 公告廣播

類型使用者故事驗收條件優先級
管理者管理者發佈公告，可指定推播對象（全棟 / 特定樓層 / 特定戶）支援 Markdown 文字 + 圖片；推播 <30s；草稿保存P0
管理者管理者可查看每則公告的已讀統計（已讀戶數 / 總戶數）僅顯示已讀戶號（不顯示姓名，符合個資法）P0
居民居民可在 App 或 LINE OA 查看歷史公告列表按時間排序；支援搜尋；已讀 / 未讀狀態P0

F-03 報修工單

類型使用者故事驗收條件優先級
居民居民可填寫報修單（類別、描述、照片），提交後收到單號支援 4 種工單類型；照片上傳 S3/R2；單號自動產生P0
管理者管理者可在 Web Dashboard 看到所有待處理工單並更新狀態狀態：待接單 / 處理中 / 已完成；可留言回覆P0
居民居民可追蹤工單進度並收到狀態更新推播每次狀態變更推播；可在 App 查看完整歷程P0

F-04 帳號 / 角色管理

類型使用者故事驗收條件優先級
委員會主委可邀請管理員、新增委員，並設定各角色權限角色：主委 / 管理員 / 委員 / 居民；權限矩陣清晰P0
管理者管理者可批次匯入住戶名單（戶號、聯絡方式）支援 CSV 匯入；自動發送邀請 LINE；重複戶號警告P0

四、非功能需求

效能 / 可靠性

  • FCM 推播 P95 <60 秒
  • API P95 <200ms（讀取）
  • 月可用率 ≥ 99.5%
  • FCM 無效 token 自動清除

安全 / 個資

  • JWT 15 分鐘 access token + 30 天 refresh rotation
  • 所有 PII 操作記錄 audit log，保存 5 年
  • 已讀名單僅顯示戶號不顯示姓名
  • GDPR-aligned 資料刪除機制

競爭洞察：智生活 80% 市佔是建立在「包裹通知 + 公告 + 低摩擦採用」上，而非付費功能的競爭壁壘。但廣告驅動的商業模式造成結構性利益衝突——對社區不友善的廣告是切入點，而非功能缺口。

二、雙軌 GTM 策略

Track A — Greenfield（未觸及市場）

進攻對象：仍用 WhatsApp / LINE 群組 / Excel 管理的 26,000 個社區

Entry point：物業管理公司（PMC）——一個 PMC 管 10–50 棟，是效率乘數

價值主張：「多棟統一管理」效率提升，而非「功能豐富」

銷售週期：8–12 週（PMC 決策者 → 試點社區 → 擴展）

Track B — Win-back（存量替換）

進攻對象：智生活廣告不滿用戶，尤其 B1 型（自管社區，決策最快）

切入點：「無廣告，管理費模式」——觸達那些已被廣告困擾的主委

移轉障礙：居民需重新下載 App；需設計流暢的資料遷移體驗

銷售週期：4–8 週（已有產品意識，決策更快）

北極星指標（North Star Metric）

週活躍管理者數 × 社區管理操作完成率

選擇此指標的理由：Linkju 的價值核心是「讓管理者效率提升」，而非居民黏著度。管理者每週持續使用且完成核心操作（登記包裹、發公告、處理工單），才代表真正創造了價值——這個指標同時捕捉了採用廣度（週活人數）與使用深度（操作完成率）。
